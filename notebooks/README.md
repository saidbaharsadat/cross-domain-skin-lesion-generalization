# Original experiment notebooks

These notebooks are the original Kaggle execution notebooks used in the accepted manuscript experiment sequence.

| Experiment | Notebook | Role |
|---|---|---|
| 01C | `01C_source_lesion_safe.ipynb` | Frozen lesion-safe internal evaluation |
| 04A | `04A_conventional_image_level.ipynb` | Conventional image-level comparison and lesion-overlap audit |
| 05A | `05A_source_only_external.ipynb` | Frozen source-only external characterization |
| 06A | `06A_multidomain_baseline.ipynb` | Five-class multidomain generalized baseline |
| 06D | `06D_soft_routed_residual.ipynb` | Frozen-backbone soft-routed residual adaptation |
| 08A | `08A_final_configuration_lock.ipynb` | Final gain selection and configuration lock |
| 08B | `08B_derm12345_post_lock.ipynb` | Post-lock DERM12345 evaluation |

The notebooks preserve their original Kaggle paths and execution outputs as provenance. Dataset paths therefore need to be adapted when reproducing the experiments outside the original Kaggle environment.

No API keys or authentication tokens were found in the seven notebooks during the public-release audit.
